📁 COMO USAR
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. EXTRAIR O ZIP
   $ unzip ibap-rj-site.zip
   $ cd ibap-rj-site

2. ABRIR NO NAVEGADOR (testar)
   $ open index.html    (Mac)
   $ start index.html   (Windows)
   $ xdg-open index.html (Linux)

3. EDITAR PÁGINAS
   Use seu editor favorito:
   • VSCode (recomendado)
   • Sublime Text
   • Atom
   • Qualquer editor de texto

4. FAZER PUSH PARA GITHUB
   Veja: GITHUB_PUSH_GUIDE.md
   (10 minutos para colocar online)


⚡ CRIANDO A PRÓXIMA PÁGINA (5 minutos)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Exemplo: Criar projetos.html

   1. Copiar template:
      $ cp TEMPLATE_NOVA_PAGINA.html projetos.html

   2. Abrir em editor (VSCode):
      $ code projetos.html

   3. Editar 3 linhas:
      Linha 15:  <title>Projetos em Destaque | IBAP-RJ</title>
      Linha 70:  <strong>Projetos</strong>
      Linha 77:  <h1>Projetos em Destaque</h1>

   4. Salvar (Ctrl+S) e testar (open projetos.html)

   5. Pronto! 🎉

   Repita para: boletim, trabalhe-conosco, certificacoes, historico, responsabilidade-social

❓ DÚVIDAS FREQUENTES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

P: As páginas funcionam sem servidor?
R: Sim! Abra arquivo.html direto no navegador (file://)

P: Preciso de React/Vue?
R: Não! HTML/CSS/JS vanilla está 100% funcional. Tudo já está pronto.

P: Como adicionar conteúdo real?
R: Abra a página em um editor de texto e edite o HTML diretamente.

P: Como colocar online?
R: Faça push para GitHub (veja GITHUB_PUSH_GUIDE.md) → GitHub Pages

P: Quanto tempo para terminar?
R: 40 minutos (30 min criar 6 páginas + 10 min testar)

P: Posso mudar cores?
R: Sim! Edite as variáveis CSS no topo de style.css:
   --azul-900: #0e2a47;
   --verde-600: #17785a;

P: O formulário de contato funciona?
R: Sim, mas precisa conectar uma serviço (Formspree é grátis)
   Veja: contato.html linha ~150
