🚀 PUBLICAÇÃO
═══════════════════════════════════════════════════════════════════════════════

  3 Opções Rápidas:

  ⭐ VERCEL (Recomendado — 2 min)
     npm install -g vercel
     cd ibap-rj-site
     vercel --prod
     → URL: ibap-rj-site.vercel.app (customize com domínio)

  🐙 GITHUB PAGES (Grátis — 5 min)
     git init
     git add .
     git commit -m "Site IBAP-RJ"
     git push -u origin main
     → URL: seu-usuario.github.io/ibap-rj-site

  🖥️  SERVIDOR PRÓPRIO (Full control — 10 min)
     FTP upload de arquivos
     Configurar web server (Apache/Nginx)
     Apontar domínio via DNS
     → URL: seu-domínio.com
